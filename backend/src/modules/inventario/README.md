# Modulo inventario

Proximo ejercicio: GET movimientos, PATCH stock y guardar movimiento.

Cuando lo desarrolles, crea estos archivos:

- `inventario.routes.js`: endpoints HTTP
- `inventario.controller.js`: req y res
- `inventario.service.js`: if, else, for, validaciones de negocio
- `inventario.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
