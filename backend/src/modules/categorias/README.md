# Modulo categorias

Proximo ejercicio: GET categorias, GET por id, POST categoria.

Cuando lo desarrolles, crea estos archivos:

- `categorias.routes.js`: endpoints HTTP
- `categorias.controller.js`: req y res
- `categorias.service.js`: if, else, for, validaciones de negocio
- `categorias.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
