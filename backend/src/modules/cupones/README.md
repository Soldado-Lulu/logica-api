# Modulo cupones

Proximo ejercicio: GET cupones, POST validar cupon, POST cupón.

Cuando lo desarrolles, crea estos archivos:

- `cupones.routes.js`: endpoints HTTP
- `cupones.controller.js`: req y res
- `cupones.service.js`: if, else, for, validaciones de negocio
- `cupones.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
