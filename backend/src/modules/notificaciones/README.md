# Modulo notificaciones

Proximo ejercicio: GET por cliente, PATCH marcar leida.

Cuando lo desarrolles, crea estos archivos:

- `notificaciones.routes.js`: endpoints HTTP
- `notificaciones.controller.js`: req y res
- `notificaciones.service.js`: if, else, for, validaciones de negocio
- `notificaciones.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
