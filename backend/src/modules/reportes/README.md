# Modulo reportes

Proximo ejercicio: GET ventas, GET top productos, GET clientes VIP.

Cuando lo desarrolles, crea estos archivos:

- `reportes.routes.js`: endpoints HTTP
- `reportes.controller.js`: req y res
- `reportes.service.js`: if, else, for, validaciones de negocio
- `reportes.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
