# Modulo pedidos

Proximo ejercicio: GET pedidos, GET detalle, POST pedido (transaccion).

Cuando lo desarrolles, crea estos archivos:

- `pedidos.routes.js`: endpoints HTTP
- `pedidos.controller.js`: req y res
- `pedidos.service.js`: if, else, for, validaciones de negocio
- `pedidos.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
