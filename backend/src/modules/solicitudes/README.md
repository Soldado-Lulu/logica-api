# Modulo solicitudes

Proximo ejercicio: POST reclamo/devolucion, GET reclamos, GET devoluciones.

Cuando lo desarrolles, crea estos archivos:

- `solicitudes.routes.js`: endpoints HTTP
- `solicitudes.controller.js`: req y res
- `solicitudes.service.js`: if, else, for, validaciones de negocio
- `solicitudes.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
