# Modulo envios

Proximo ejercicio: GET envios, POST envio, PATCH entregar.

Cuando lo desarrolles, crea estos archivos:

- `envios.routes.js`: endpoints HTTP
- `envios.controller.js`: req y res
- `envios.service.js`: if, else, for, validaciones de negocio
- `envios.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
