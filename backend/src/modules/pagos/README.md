# Modulo pagos

Proximo ejercicio: GET pagos, POST registrar pago.

Cuando lo desarrolles, crea estos archivos:

- `pagos.routes.js`: endpoints HTTP
- `pagos.controller.js`: req y res
- `pagos.service.js`: if, else, for, validaciones de negocio
- `pagos.repository.js`: SQL seguro con parametros $1, $2

Mira el modulo `clientes` como ejemplo antes de continuar.
No se registran estas rutas hasta que tu las implementes.
